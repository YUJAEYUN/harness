# 촉매 캘린더 — 어떤 이벤트가 어느 시나리오로 확률을 옮기는가

- **작성**: scenario-team-lead
- **기준일**: 2026-07-31 (기준 지수: 2026-07-30 종가 **5,593.56**)
- **입력**: 3개 시나리오의 확률 업데이트 조건(낙관 §8 / 비관A §4 / 비관B §6-1) + 조기경보 지표(낙관 §9 EW-1~9 / 비관A §5 EW-1~10 / 비관B §7 F1~F12) + Risk/Reward 무효화 조건을 하나로 통합
- **적용 스킬**: `team-synthesis-review`, `data-sourcing-protocol`

> ## 이 문서의 성격 — 반드시 먼저 읽을 것
>
> 1. **이것은 자동 트리거가 아니다.** 본 하네스는 **2026-07-31 기준 1회성 정적 스냅샷 분석**이며, "언제 다시 실행하라"는 스케줄러가 아니다. 아래 표는 **사용자가 스스로 참고할 정리표**다.
> 2. **투자 지시가 아니다.** 진입·청산·포지션 사이징을 포함하지 않는다. "확률 이동 방향"은 세 시나리오 중 어느 쪽의 논리가 강화/약화되는가에 대한 조건부 서술이다.
> 3. **화살표는 크기가 아니라 방향이다.** ↑↑↑ = 결정적 / ↑↑ = 큼 / ↑ = 중간. **각 구축자가 부여한 수치 이동폭(예: "40%→28%")은 그 확률 자체가 검증을 통과하지 못했으므로**(`02_scenario_synthesis.md` §2-2) **본 캘린더는 수치를 옮기지 않고 방향만 기록**한다.
> 4. **팀 표준 처분이 반영되어 있다.** 되돌림 비율 기반 무효화(비관B 7,035)는 폐기됐고, 청산 75%·정책 60% 통계에 근거한 항목은 강등 또는 병기 의무가 붙었다.
> 5. **세 시나리오는 지수 레벨로 판별되지 않는다.** 1차 판별 변수는 **12MF EPS 되돌림 폭**이며(§1 참조), 가격 항목은 후행 확인용이다.

## 1. 최상위 판별 변수 — 이 하나가 세 시나리오를 가른다

**팀 표준 판별 변수: 코스피 총계 12MF EPS의 되돌림 폭** (기산점 1,182.4, 2026-07-28 역산)

| EPS 수준 | 기산점 대비 | **해당 시나리오** | 관측 방법 |
|---|---|---|---|
| **> 1,064.2** | −10% 이내 | **낙관** | 주간 컨센서스 — Wisefn / FnGuide / 연합인포맥스 / 에프앤가이드 |
| **945.9 ~ 1,064.2** | −10% ~ −20% | **비관A** | 동일 |
| **< 945.9** | −20% 초과 | **비관B** | 동일 (−30% 초과 = 비관B의 강한 형태) |

```
검산 [DERIVED]: 1,182.4 × 0.90 = 1,064.16   (낙관 §6-2 H1 정의)
                1,182.4 × 0.80 =   945.92   (비관A §6-2 하방 무효화 자기 선언)
                1,182.4 × 0.70 =   827.68   (비관B §4 판별표)
```

> **경계의 출처**: 새로 만든 숫자가 아니라 **각 시나리오의 자기 선언값**이다. 낙관은 H1을 *"−10% 초과 하향되지 않는다"*로 정의했고, 비관A는 *"E 하향폭 −20% 초과 = 분모 붕괴 = 비관B 전환"*을 자기 무효화로 선언했다.
>
> **한계 3가지 (병기 의무)**: (a) 기산점 1,182.4는 단일 `[WEB-미확인]` PER 5.10의 순환 변환값이며 E-03 미해소(`6,023.66/5.10 = 1,181.11`로 0.109% 불일치 존재). (b) −20~−30% 구간은 비관B가 자기 밴드 산정에 쓰지 않은 "약한 형태" 구간이다. (c) **EPS 축을 확정해도 세 시나리오의 지수 밴드 중첩은 해소되지 않는다** — 매핑이 PER 가정에 의존하기 때문이다.

**보조 판별 변수 (지수 레벨로 갈리지 않는 부분)**

| 축 | 낙관 | 비관A | 비관B |

## 5. 이 캘린더 사용 시 반드시 함께 읽어야 할 단서 5건

| # | 단서 |
|---|---|
| **1** | **최우선 판별자(CAT-01, 2027 capex 가이던스)는 트리거되지 않을 수 있다.** 메타 CFO가 2027 가이던스 제시를 명시적으로 거부한 것처럼 기업들이 계속 침묵하면, 이 지표는 **"반증도 확증도 되지 않는 상태"**로 남는다(E-04, 구조적 데이터 공백). 이 경우 판별 부담은 **전량 후행 지표(CAT-07·CAT-08·CAT-13)로 이전**되며, 시나리오 갱신은 **느리고 사후적**이 된다 |
| **2** | **애매한 상태가 지속될 경우의 사전 규칙.** 비관B가 유일하게 이를 명문화했다 — *"F1~F5가 전부 애매한 상태로 2분기 경과 시 확률을 20% → 15%로 하향"*(사후 합리화 방지). **낙관·비관A에는 대응 규칙이 없다.** 즉 **정보 부재가 장기화될 때 세 시나리오 중 하나만 자기 확률을 자동 감액하는 비대칭**이 존재한다 |
| **3** | **모든 임계값의 `[RAW]` 태그는 0건이다.** 13개 산출물 전체에서 `[RAW]` 0건. 임계값의 기준이 되는 현재값(EPS 1,182.4, PER 4.73, PBR 1.4, VKOSPI, 신용잔고 등)이 전부 `[WEB]` 계열이며, **원 수치가 틀리면 임계값도 함께 틀린다** |
| **4** | **세 시나리오의 확률 자체가 검증을 통과하지 못했다.** 35/40/20의 상대 순서는 후속 검증에서 유지되지 않으며, 산정 방법이 서로 달라 비교 불가능하다. **따라서 이 캘린더의 "확률 이동"은 상대적 방향이며, 절대 확률의 갱신이 아니다** (`02_scenario_synthesis.md` §2-2) |
| **5** | **본 하네스는 1회성 정적 스냅샷이다.** 이 캘린더는 자동 재실행 트리거가 아니라 사용자 참고용 정리표이며, 위 이벤트가 실제 발생했을 때의 재평가는 사용자 판단에 따른 별도 실행이 필요하다 |
