### 2. CXMT 가격 할인폭 (E-03 항목 4, 해소)
- **[WEB-교차확인]** (5개 매체 일치): CXMT는 삼성·SK 대비 소비자가 기준 실질 할인폭이 크지 않음(약 2.2%/$60 수준) — "저가 공세"라는 통념과 반대. 단, IPO 밸류에이션(PBR 2.4배)은 SK하이닉스·Micron·Nanya 평균 대비 56% 할인.
- 출처: [헤럴드경제](https://biz.heraldcorp.com/article/10820897), [AI타임스](https://www.aitimes.com/news/articleView.html?idxno=213212), [테크월드](https://www.epnc.co.kr/news/articleView.html?idxno=404816) 등
- **주의**: 브리핑에서 언급된 "10% vs 30%" 할인율 논쟁과는 다른 프레임(소비자가 vs 밸류에이션)이라, 원래 상충이 완전히 해소된 것은 아님 — 두 수치 모두 사실일 수 있음(다른 대상을 측정).

### 4. DRAM/NAND 3Q26 계약가 방향 (E-03 항목 1, 부분 해소)
- **[WEB-교차확인]**: DRAM 계약가 +13~18% QoQ, NAND +10~15% QoQ (3Q26 전망, TrendForce)
- 흥미로운 발견: **DDR4 스팟가($2.10/Gbit)가 HBM3e 계약가($1.70/Gbit)를 이미 상회** — 스팟시장이 서버 수요에 좌우되는 구조
- 출처: [TrendForce 2026-07-03](https://www.trendforce.com/presscenter/news/20260703-13134.html)
- 다만 이는 "계약가 전망"이지 사용자가 원한 "실시간 스팟가 정밀 수치"는 아님 — DRAMeXchange 등 유료 데이터베이스 없이는 스팟가 정밀 시계열 확보 불가.

## 끝내 해소 못한 항목 — 사용자가 직접 받아야 하는 것

### KRX 투자자별(외국인/기관/개인) 거래실적 원자료 — **가장 중요, E-02 해소의 핵심**
WebFetch로 시도했으나 해당 페이지가 JavaScript로 폼을 제출해야 데이터가 로딩되는 구조라(정적 HTML에 실제 수치가 없음) 확보 불가능했습니다. **직접 받는 방법**:
1. https://data.krx.co.kr 접속
2. 상단 메뉴 "통계" → "주식" → "투자자별 거래실적" (또는 검색창에 "투자자별 거래실적" 입력)
3. 조회 구분: "코스피", 기간: 2026-07-01 ~ 2026-07-31 (또는 필요 기간)
4. 조회 후 화면 우측 상단 "다운로드" 버튼(CSV/Excel) 클릭
5. 받은 파일을 `_workspace/kospi-bottom/00_input/`에 넣어주시면 제가 반영해서 E-02(외국인 7월 순매도 총액 −17.9조 vs −22.45조 모순, 7/29 개인 순매매 부호 반대 문제)를 해소하겠습니다.

이 데이터가 없으면 두 항목 모두 최종 산출물에 "[WEB-미확인] — 소스 간 상충, 원자료로만 해소 가능"으로 남습니다.
