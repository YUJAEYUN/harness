# Dashboard Assembly

`_workspace/kospi-bottom/01_public-research-evidence-registry.md`, `01_research_synthesis.md`, `02_scenario_synthesis.md`, `02_catalyst_calendar.md`, `03_risk-manager_report.md`, `03_ic_memo.md`를 하나의 정적 HTML 대시보드로 조립한다. 데이터는 오늘 스냅샷으로 고정하고, 인터랙션은 클라이언트 사이드 UI로 한정한다.

## 착수 전

차트/색상/레이아웃을 다루기 전에 `dataviz` 스킬을 먼저 로드해 색상 팔레트와 폼 휴리스틱을 따른다. 시각 자체를 디자인하는 결정(패널 레이아웃, 타이포그래피 등)이 크면 `artifact-design` 스킬도 참조한다.

## 첫 화면 의사결정 블록 — 다른 패널보다 먼저

첫 화면에서 목표지수나 시나리오 밴드보다 다음 네 항목을 먼저 보여준다.

1. **현재 판정**: 예) 기술적 바닥 후보 / 실적 바닥 미확인. 확인 수준을 넘는 단정 금지
2. **확인된 근거**: A/B등급 또는 공식/RAW 근거만 3~5개
3. **미확인 핵심**: 결론을 바꿀 데이터 공백 3~5개
4. **판단 변경 조건**: 어떤 지표가 어떤 방향으로 움직이면 어느 해석이 강화·약화되는지

각 행에 최신 관측일, 출처 태그, A~D 증거등급을 표시한다. “무엇을 봐야 하는지”가 스크롤 없이 보여야 한다.

## 쉬운말 화면과 전문가용 근거 분리 — 필수

대시보드의 기본 화면은 금융업 종사자가 아닌 사용자를 기준으로 작성한다. 내부 보고서의 약어와 분류명을 그대로 복사하지 않는다.

- **기본 화면:** 결론, 의미, 아직 모르는 것, 판단이 바뀌는 조건을 쉬운 한국어로 표시한다.
- **전문가용 근거:** 원문 필드명, 약어, 산식, 증거 코드가 추적에 꼭 필요하면 `<details>` 안에 넣는다.
- 괄호로 영문 약어를 반복하는 방식은 쉬운 설명으로 인정하지 않는다. 약어를 몰라도 본문 전체가 이해돼야 한다.
- 숫자만 보여주지 말고 바로 옆에 `이 숫자가 뜻하는 것`을 붙인다.
- 표 머리글도 내부 용어 대신 질문형 또는 의미형 문구를 사용한다.

| 내부 표현 | 기본 화면 표현 |
|---|---|
| 12MF EPS / EPS | 앞으로 예상되는 기업 이익 |
| PER / P/E / multiple | 주가가 이익에 비해 얼마나 비싼지 보여주는 값 |
| revision breadth | 이익 전망이 내려가는 기업의 범위 |
| capex | 대형 기술기업의 실제 투자와 주문 |
| DRAM contract / spot | 메모리 반도체의 장기 거래가격 / 당일 거래가격 |
| source family | 서로 독립적인 원자료 |
| derived | 원자료로 계산한 값 |
| assumption | 확인되지 않은 가정 |
| bull / bear | 좋은 흐름 / 조정 흐름 / 깊은 침체 |
| IC conditional | 최종 검토: 추가 확인 필요 |

완성 후 화면에 보이는 텍스트를 기준으로 `EPS`, `PER`, `P/E`, `12MF`, `revision breadth`, `capex`, `Risk/Reward`, `EV`, `IC`, `source family`, `bull`, `bear`를 검색한다. 고유한 원문 명칭으로 반드시 필요한 경우가 아니면 쉬운말로 다시 쓴다.

## 필수 패널

1. **낙폭/속도 패널**: 현재 vs 역사적 분포, percentile (historical-market-analyst 산출물)
2. **밸류에이션 패널**: PER/PBR 추이, P/E 중 무엇이 원인인지 분해 (valuation-quant-analyst 산출물)
   - 열 이름을 “평가배수 기여 / 이익 기여(상쇄 가능)”로 사용하고 부호를 보존
   - “가격 86% / 이익 14%”처럼 종속변수와 원인을 혼동하거나 상쇄 부호를 제거한 표현 금지
3. **수급 패널**: 외국인/기관/개인 순매매 추이, 과거 대비 강도 (market-microstructure-analyst 산출물)
4. **시나리오 패널**: 낙관/비관A/비관B 확률과 조기경보 지표 상태 (scenario-team 산출물)
5. **시나리오별 병렬 해석 패널**: 각 시나리오마다 "1층 근거 데이터 → 해석 → 교차 레드팀 반박 → 정량검증 → 미확인 가정" 흐름을 그대로 노출 — 요약하거나 한쪽만 보여주지 않는다
6. **Risk/Reward 패널**: 시나리오별 목표 밴드·무효화 조건·업다운사이드 비율·EV 예시를 표/차트로 정리 (시나리오 구축자 산출물). 밴드는 "예측"이 아니라 "이 시나리오가 맞다면"이라는 조건부 라벨을 항상 함께 표시
7. **촉매 캘린더 패널**: `02_catalyst_calendar.md`를 타임라인 또는 체크리스트 UI로 표시 — 어떤 이벤트가 어느 시나리오로 확률을 이동시키는지
8. **IC 심사 패널**: `03_ic_memo.md`의 시나리오별 PASS/CONDITIONAL/CHALLENGE 등급, 구조적 리스크(risk-manager) 요약, 사후검토 체크리스트를 표시. 이 패널 최상단에 "이 등급은 논리·근거 검증 상태이며 매수/매도 신호가 아닙니다"를 다른 배너와 별개로 한 번 더 명시 (섹션 자체가 오해받기 가장 쉬운 부분이므로 이중 고지)
9. **역사적 이익 사이클 패널**: 사건별 12MF EPS 고점·저점·하락률·하향 기간·주가 저점과의 시차·원 데이터 계열을 표시. “과거 최종 하락 범위”와 “실시간 반등 트리거”를 분리
10. **증거 신뢰도 패널**: A~D 등급 설명, 보고서 n / 독립 source family n, 주요 상충 수치, [ASSUMPTION] 격리 목록을 표시

## 출처 태그 시각화 (필수)

모든 수치 옆에 `[RAW]`/`[OFFICIAL]`/`[REPORT-A~D]`/`[WEB]`/`[DERIVED]`/`[ASSUMPTION]` 태그를 구분해 표시한다. REPORT 툴팁에는 발행사·보고서 날짜·페이지·원 데이터 제공자·source family를 표시한다. 태그 없는 수치는 넣지 않는다.

`[ASSUMPTION]`은 관측 사실과 다른 색·테두리를 사용하고 “민감도 입력값이며 역사적으로 검증된 경계가 아님”을 항상 표시한다.

기본 화면의 태그는 `[REPORT-A]`, `[DERIVED]` 같은 내부 코드를 그대로 보여주지 않고 `보고서 원문 확인`, `공식 자료`, `원자료로 계산`, `확인되지 않은 가정`으로 표시한다. 내부 코드는 툴팁이나 `전문가용 근거` 안에서만 보존한다.

## 팩트 패널 vs 해석 패널 구분 (필수)

리서치팀 산출물(사실/1차해석)과 시나리오팀 산출물(해석/시나리오)을 시각적으로 명확히 구분한다 — 배경색, 아이콘, 또는 섹션 헤더 스타일 차이로. 사용자가 한눈에 "이건 확인된 사실이다"와 "이건 시나리오적 해석이다"를 구분할 수 있어야 한다.

역사적 관측 범위와 시나리오 스트레스 가정도 별도 레이어로 구분한다. 예를 들어 과거 EPS −32~−37% 관측 범위와 임의의 EPS −20% 스트레스는 같은 축에서 같은 종류의 트리거처럼 보이면 안 된다.

## 미확인 가정 섹션

대시보드와 별도로 `output/kospi-bottom/미확인_가정.md`를 생성한다. `_workspace/kospi-bottom/01_research_escalation_log.md`(팀 내 조정), `_workspace/kospi-bottom/02_scenario_escalation_log.md`(팀 내 조정), 웨이브3에서 나온 미해결 항목, 그리고 Phase 5에서 사용자에게 확인받지 못하고 진행한 항목 전부를 빠짐없이 기록한다. 대시보드에는 이 문서로 연결되는 링크나 배너를 넣는다.

## 사후검토(post-mortem) 섹션

`03_ic_memo.md`의 사후검토 체크리스트를 대시보드 하단(또는 별도 탭)에 그대로 노출한다 — 사용자가 나중에 스스로 "이 분석이 어느 방향으로 맞아가고 있는지" 대조할 수 있는 도구다. 자동 재실행이나 알림 기능은 없음을 명시 (1회성 정적 분석).

## 투자 조언 아님 고지 (필수, 눈에 띄는 위치)

대시보드 최상단과 최종 요약부에 "이 하네스는 역사적 데이터 비교와 확률적 사고 구조를 제공하는 것이지, 매수/매도 추천이 아닙니다. Risk/Reward 밴드와 IC 등급도 마찬가지로 프레임워크와 논리 검증 결과일 뿐, 포지션 사이징이나 매수 지시가 아닙니다."를 고정 배너로 표시한다.

## 하나의 결론으로 수렴시키지 않기

대시보드의 시나리오 패널은 세 시나리오를 병렬로 제시하지, 어느 하나를 "정답"처럼 강조하지 않는다. 세 시나리오 카드는 동일한 시각적 비중(크기, 위치 우선순위)으로 배치한다.
