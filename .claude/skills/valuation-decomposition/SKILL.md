# Valuation Decomposition — P/E 분해

`data-sourcing-protocol` 스킬의 태깅 규칙을 함께 적용한다. 이 스킬은 하네스 전체에서 가장 중요한 분석 중 하나를 다룬다: **저PER이 주가 하락 때문인지 이익 급증 때문인지**.

## 왜 이 분해가 중요한가

과거 급락 바닥은 대부분 "투매로 주가만 빠져서 PER이 낮아진" 경우다. 이번 사례는 삼성전자·SK하이닉스의 HBM 실적이 급증하며 이익(E) 자체가 커진 상태에서 급락이 겹쳤다 — 그래서 현재 PER이 낮아 보여도 과거의 "투매성 저PER 바닥"과 동일 선상에서 비교하면 안 된다. 이 분해 없이 "PER이 역사적으로 낮다"는 결론만 내면 시나리오팀 전체가 잘못된 전제 위에서 작업하게 된다.

## 분해 절차

1. 랠리 고점과 현재의 지수 P, 12MF EPS E, 암묵적 평가배수 M=P/E를 같은 날짜·같은 데이터 정의로 확보한다.
2. 먼저 관측값을 검산한다: P₁/P₀ = (E₁/E₀) × (M₁/M₀).
3. 지수 하락 원인을 **평가배수 변화와 이익 변화**로 분해한다. “가격 기여”라는 표현은 종속변수인 지수 가격과 원인을 혼동하므로 금지한다.
4. 기본 분해는 로그 가법식을 사용한다.

   ```
   ln(P₁/P₀) = ln(E₁/E₀) + ln(M₁/M₀)
   earnings contribution = ln(E₁/E₀) / ln(P₁/P₀)
   multiple contribution = ln(M₁/M₀) / ln(P₁/P₀)
   ```

5. 부호를 보존한다. 지수가 하락하는 동안 EPS가 상승했다면 이익은 하락 원인이 아니라 **상쇄 요인**이다. 예: multiple 114%, earnings −14%(상쇄)처럼 합이 100%가 되게 표시한다. 이를 86%/14%처럼 두 개의 양(+) 기여로 바꾸지 않는다.
6. 독자가 퍼센트포인트로 이해해야 하면 순서 의존성을 없앤 Shapley 분해를 보조로 제시한다.

   ```
   ΔP = C_E + C_M
   C_E = M₀ΔE + 0.5ΔEΔM
   C_M = E₀ΔM + 0.5ΔEΔM
   ```

7. 두 기여분을 `[DERIVED]` 태그와 함께 원 입력값·계산식·반올림 전 값을 노출한다.
8. 이익 컨센서스 리비전 추이(상향/하향/유지)를 별도로 조사한다. E가 확정실적인지 전망치인지, 실제 시계열인지 지수와 PER로 역산한 값인지 구분한다.
9. raw 시계열이 없으면 public-research-evidence registry의 A/B등급 관측값으로 교차확인하고 C등급 단독 수치로 정밀 분해하지 않는다.

## 출력 시 주의

- EPS·PER·PBR은 정밀 수치이므로 `[RAW]` 최우선, 없으면 교차확인 절차(data-sourcing-protocol 4-1) — 이 항목은 시나리오 판단에 직결되므로 불일치 시 사소함으로 넘기지 말고 적극적으로 `NEEDS_CLARIFICATION` 고려
- semiconductor-analyst의 실적 데이터를 E 추정 근거로 활용하되, 출처는 원래 데이터의 출처를 그대로 유지 (재가공 시 원출처 명시)
- 10%·20% EPS 하향 같은 스트레스 입력은 `[ASSUMPTION]`으로 표시하고 역사적으로 검증된 판별선처럼 서술하지 않는다.
- 출력 표의 열 이름은 “평가배수 기여 / 이익 기여(상쇄 가능)”로 고정한다.
