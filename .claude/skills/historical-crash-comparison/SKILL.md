# Historical Crash Comparison

`data-sourcing-protocol` 스킬의 태깅 규칙을 함께 적용한다.

## 비교 대상 사례

1987 블랙먼데이, 1997 외환위기, 2000-03 닷컴+카드사태, 2008 금융위기, 2011 유럽재정위기, 2015-16 차이나쇼크, 2018 볼마게돈, 2020 코로나, 2022 긴축발작, 2024 엔캐리 청산.

## 비교 축

| 축 | 정의 |
|----|------|
| 고점→저점 낙폭(%) | 사례별 지수(코스피 또는 비교 가능한 지수) 고점 대비 최대 낙폭 |
| 낙폭 소요기간 | 고점부터 저점까지 걸린 기간(속도) |
| 되돌림 비율 | 저점 이후 특정 기간 내 회복된 비율 |
| 회복 소요기간 | 고점 수준을 재돌파하기까지 걸린 기간 |
| 저점 당시 밸류에이션 | 가능하면 PER/PBR |
| 반등 트리거 유형 | 정책 개입 / 실적 반등 / 유동성 공급 / 자연 소진 등 |

### 이익 사이클 축 — 자료가 있는 사례에 필수

| 축 | 정의 |
|---|---|
| 12MF EPS 고점·날짜 | 해당 하강 사이클 직전의 12개월 선행 EPS 최고 관측값 |
| 12MF EPS 저점·날짜 | 같은 정의·같은 데이터 계열에서 확인한 최저 관측값 |
| EPS 고점→저점 하락률 | EPS_min / EPS_max - 1 |
| EPS 하향 지속기간 | 고점 날짜부터 저점 날짜까지 |
| 주가 저점과 EPS 저점의 시차 | 주가가 먼저면 음(-), EPS가 먼저면 양(+)으로 규약 고정 |
| 이익수정 확산도 | 가능하면 상향/하향 종목 수 또는 revision ratio |
| 원 데이터 계열 | FnGuide/QuantiWise, Refinitiv/I/B/E/S, Bloomberg, FactSet 등 |

01_public-research-evidence-registry.md의 보고서 증거를 사용하되, 같은 원 데이터 계열과 같은 표본을 사용한 보고서는 독립 관측치로 중복 계산하지 않는다.

## Percentile 산출

현재 코스피의 낙폭·속도·밸류에이션이 위 10개 사례 분포에서 어느 위치인지 계산한다. `[DERIVED]` 태그와 함께:
- 모집단(어떤 사례들을 포함했는지, 왜 이 10개인지)
- 계산 방법(단순 순위 백분위인지, 정규분포 가정 z-score인지)
을 명시한다. 표본이 10개뿐이라는 한계를 반드시 보고서에 밝힌다 — 이는 quant-validator가 재검증할 항목이다.

## 역사적 이익 하강 범위 산출

1. A등급 표를 우선하고, 부족할 때 B등급 차트 복원값을 범위로 추가한다.
2. 사건별로 동일한 metric definition과 source family 안에서 고점·저점을 짝짓는다.
3. 사건별 하락률·기간을 먼저 제시하고, 평균·중앙값은 유효 표본 수와 함께 별도로 계산한다.
4. 보고서 문구와 표의 산술이 다르면 표를 재계산하고 차이를 명시한다.
5. 최소 3개 비교 가능한 사건과 2개 독립 source family가 없으면 “역사적 임계값”이라 부르지 말고 “선택된 사례의 기술 범위”라고 부른다.
6. 10%·20% 등 보고서의 스트레스 가정은 [ASSUMPTION]으로 격리하고 실제 관측 하락률 분포에 포함하지 않는다.
7. 역사적 EPS 저점 구간과 실시간 판별 트리거를 구분한다. 과거 최종 낙폭 −30%대는 사후 기술값이지 “−30%가 되면 즉시 반등” 신호가 아니다.

## 반등 트리거 검증

정책 발표일 하나를 원인으로 단정하지 않는다. 사례별로 정책/충격 완화 → 환율·신용스프레드 안정 → 수급 안정 → 주가 저점 → EPS 하향 속도 둔화 → EPS 저점 순서를 날짜로 정리한다.

“발표와 반등이 근접했다”는 상관관계와 “발표가 반등을 유발했다”는 인과 주장을 분리한다.

## 시나리오 매핑 태깅

각 사례에 "구조적 vs 순환적", "펀더멘털 훼손 여부" 태그를 붙인다. 이는 판단이 아니라 분류 작업이다 — 예: 2018 볼마게돈은 브리핑에서 이미 낙관 시나리오의 유사사례로, 2000-03 닷컴버블은 비관B의 유사사례로 지정돼 있으므로, 그 분류 기준(펀더멘털 훼손 여부)을 다른 사례에도 동일하게 적용한다.

## 출력 시 주의

- 오래된 사례(1987, 1997)는 소스별 수치 편차가 크다 — 교차확인 절차(data-sourcing-protocol 4-1) 특히 엄격히 적용
- 표본이 "유명한 위기"에 편중돼 있다는 표본편향 가능성을 스스로 명시
- 보고서 개수와 독립 source family 개수를 모두 밝히고, 현재 지수 구성 변화 때문에 과거 코스피와 직접 비교하기 어려운 점을 명시
