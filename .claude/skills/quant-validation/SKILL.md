# Quant Validation — 통계적 한계 검증

이 스킬은 "어느 시나리오가 맞는가"에 관여하지 않는다. "이 숫자가 이 주장을 통계적으로 뒷받침할 만큼 탄탄한가"만 판단한다.

## 점검 체크리스트

1. **표본 편향**: historical-market-analyst가 비교한 과거 사례가 "유명한 위기 10개"에 편중돼, 덜 극적이지만 더 흔한 조정 국면은 빠져있지 않은가 (생존편향 — 회복하지 못한 사례가 표본에서 체계적으로 빠졌는가)
2. **과최적화**: percentile·회귀 등 계산이 소수 관측치(예: 10개 사례)에 과도하게 의존해, 표본 하나만 바뀌어도 결론이 크게 흔들리는가
3. **상관 vs 인과**: "A와 B가 같이 움직였다"는 서술이 "A가 B를 유발했다"로 비약하지 않았는가
4. **표본 크기**: 결론의 확신도에 비해 근거 관측치 수가 너무 적지 않은가
5. **계산 재검산**: `[DERIVED]` 태그가 붙은 모든 계산(P/E 분해, percentile 등)의 계산식을 직접 재계산해 원 수치와 일치하는지 확인
6. **보고서 중복 표본**: 여러 발행사가 같은 FnGuide/Refinitiv/Bloomberg 계열과 같은 사건 표본을 인용했는데 이를 독립 증거로 중복 계산하지 않았는가. 보고서 n과 독립 source family n을 재계산한다.
7. **관측값/가정 혼동**: 목표가 산출용 EPS −10%·−20% 스트레스가 과거 관측 임계값이나 실시간 트리거로 승격되지 않았는가.
8. **정의·빈티지 일치**: KOSPI/KOSPI200/MSCI Korea, FY1/12MF, 일간/월간, 보고서 발행 당시 값/사후 수정값이 혼합되지 않았는가.
9. **보고서 내부 산술**: 본문이 “평균 −30%”라고 요약해도 표의 사건별 값 평균이 다른 경우 직접 재계산하고 차이를 기록한다.
10. **기여도 부호**: 지수 하락 중 EPS 상승을 하락 기여로 표시하지 않았는가. 로그 또는 Shapley 분해에서 기여도 합과 부호가 맞는지 확인한다.

## 심각도 판정

각 발견사항을 **경미**(서술을 다듬으면 해결)와 **중대**(결론의 근거 자체가 흔들림)로 구분한다. 중대 판정 항목은 scenario-team-lead에게 재작업을 명시적으로 요청한다.

## 중립성 유지

특정 시나리오의 통계적 약점을 지적하는 것이 그 시나리오를 "틀렸다"고 판단하는 것은 아니다. 통계적 한계와 시나리오의 타당성은 별개 층위임을 보고서 서두에 명시한다.

## 출력 형식

```
## 표본편향 점검
## 준원자료 독립성 점검 (보고서 n / source family n)
## 관측값·가정·트리거 분리 점검
## 과최적화 점검
## 상관/인과 점검
## 계산 재검산 (DERIVED 항목별 표: 원 수치 / 재계산 수치 / 일치여부)
## 종합: 항목별 (주장 → 한계 → 심각도[경미/중대])
```
